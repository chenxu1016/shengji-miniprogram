# ============================================
# 升级扑克 - 微信小程序后端
# Node.js WebSocket 服务器
# ============================================

## 项目结构
- `backend/` — WebSocket 后端 (Node.js + TypeScript)
- `frontend/miniprogram/` — 微信小程序前端

## 快速开始
```bash
cd backend
npm install
npx tsc
node dist/server.js
```

## 部署
后端可部署到任意支持 Node.js 的云平台：
- **Render**: 用 render.yaml 一键部署（免费）
- **Railway**: 用 railway.toml 一键部署
- **Fly.io**: 用 fly.toml 一键部署
- **Docker**: 直接构建镜像部署

所有平台都支持通过 GitHub 仓库一键部署。
